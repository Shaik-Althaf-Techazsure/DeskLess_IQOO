DeskLess

Site inspection reports, without the desk. Photograph each issue, say what is wrong, and get an English PDF report. Everything runs on the phone, in airplane mode too.

Download DeskLess.apk

Android 7 or later, 64-bit ARM phone. Built from this repository by docker compose up --build.

Install on the phone

  1. Open this page on the phone: http://<this computer's IP>:8700 (phone and computer on the same Wi-Fi or hotspot).
  2. Tap Download DeskLess.apk, then open the downloaded file.
  3. Android asks whether this browser may install apps. Allow it, then tap Install.

The same file is in the apk folder next to docker-compose.yml, for sending with iQOO Office Kit file transfer or a cable.

Phones that should pass reports to each other all need this same build, and Google Play services.

AI models

The models are not inside the APK (about 2.8 GB). Copy these files to a folder on the phone, then open Models in the app and import that folder:

  • small-encoder.int8.onnx, small-decoder.int8.onnx, small-tokens.txt (Whisper small, speech to English text)
  • silero_vad.onnx (splits long voice notes)
  • gemma-4-E2B-it.litertlm (Gemma 4 E2B, fills the report fields and checks the photo)

Without them the app still takes photos and voice notes, accepts typed notes and builds the PDF; built-in rules then fill only the title and the severity.
